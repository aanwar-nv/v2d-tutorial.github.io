# V2D Tutorial

Website for the V2D Tutorial.

Content is driven by `assets/js/config.js` (speakers, organizers, schedule) and `index.html` (section copy). Drop headshots into `assets/images/` and update the paths in `config.js`.

Template adapted from [eval-deploy.github.io](https://github.com/AbrarAnwar/eval-deploy.github.io).
